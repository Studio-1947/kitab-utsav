# Tag

A small pill for a discount beside a price ("20% off"), in `accent` on `discount-tint`.

**The consumer provides** the short text: a percentage or one or two words.

**Rules**
- `tag` style: 0.7rem / 600, `radius-pill`, 2px × 8px padding, never wraps.
- Sits next to the price, never on a book cover.
- On phones it moves to its own line under the price so every card keeps the same height.
